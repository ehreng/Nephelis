Project AETHER is now running on **AETHER OS**: an AI-coordinated, adaptive operating system that keeps the mission moving with daily briefs, prioritized tasks, and public contribution loops — without a traditional hierarchy.

### What changed

- **Daily Mission Loop** is live: DETECT → PLAN → EXECUTE → VERIFY. Briefs land in the repo (`aether-os/briefs/`) with claimable work and acceptance criteria.
- **Collaborators and contributors welcome** at every skill level:
  - **L1** — content, social, ideas, simple graphics
  - **L2** — code, simulations, technical writing, design
  - **L3** — hardware, regulatory, deep engineering (review gated)
- New team members can claim tasks via GitHub Issues (`claiming`) or the site volunteer form. Verified work is attributed in the contribution log.
- Public OS overview: [/aether-os](/aether-os) · architecture in the repo · build-in-public by design.

### How to join

1. Read the latest Mission Brief and [CONTRIBUTING](https://github.com/ehreng/Nephelis/blob/main/CONTRIBUTING.md).  
2. Claim an L1 or L2 issue — or propose one.  
3. Ship evidence (PR, notes, assets). We verify and log it.

Founder role remains **Founder Emeritus / Strategic Oversight** — vision and high-stakes overrides stay human; day-to-day coordination is largely automated.

**Not for consumption. For continuation.** Venus cloud layer remains the target. Launch window **Q4 2027**.
