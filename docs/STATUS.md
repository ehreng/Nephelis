# Public Status — Project AETHER

**Updated:** 2026-08-11  

This is the honest status page for humans and agents. Marketing vision ≠ engineering maturity.

## One-line status

**Early-stage concept + documentation + open collaboration OS. Pre-hardware. No committed launch date.**

## What is real

- Public site and interactive trajectory planner (illustrative)  
- Draft CONOPS, requirements, materials test protocol, risk list  
- Structured mission data in git (`site/content/data/`)  
- AETHER OS: daily briefs, L1–L3 contribution model, GitHub as SSOT  
- Founder: Ehren Goossens (Founder Emeritus / Strategic Oversight)  

## What is not real (yet)

- Flight hardware, acid-chamber results, or envelope prototypes  
- Entry system / heatshield / inflation hardware  
- Selected flight solar, rad-hard avionics, or CubeSat  
- Submitted FAA/FCC applications  
- Named advisors with published Venus aerobot flight experience  
- Live crowdfund checkout (pending configuration)  
- A funded path to a 2027 Venus launch

**$500k** = early ground / prototype / community campaign scale.  
**Not** a credible end-to-end Venus flight budget. Entry systems alone often exceed that before balloon or relay.

## Authority claims

**None.** “Backed by veterans from SpaceX / JPL / DARPA / ESA / Blue Origin” has been **removed**. Credibility requires named people with permission, or silence.
