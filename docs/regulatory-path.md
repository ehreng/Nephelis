# Regulatory & Compliance Path (Draft Notes)

**Status:** Working notes — **not filings**. No applications have been submitted as of 2026-08-11.  
**Goal:** Document the path honestly so the project does not pretend regulatory work is done.

## Why this exists

A private Venus probe will eventually touch:

- **Launch / payload** (FAA commercial space transportation or rideshare integrator requirements)
- **Spectrum / radio** (FCC for space stations / experimental licenses depending on architecture)
- **Export control** (ITAR/EAR classification of hardware and technical data)
- **Planetary protection** (COSPAR / NASA policy context for Venus; DNA / biological sample tiers need counsel)

Until counsel is engaged and applications are filed, all of the above are **research tasks**, not completed work.
